Logical Entity Name  PERSON_DIM 
Default Table Name  PERSON_DIM 
Physical Only  NO 
Do Not Generate  False 
Dimensional Model Table Type  Dimension 
Dimension Table Type  Fixed 
Owner   
Definition  
One person record as one source sent it, unmatched; client, insured and agent records each their own person (mart design D-10). Each ghost key once, with no role (D-14).
 
Note

PERSON_DIM Columns 
ColumnName  Domain  Datatype  NULL  Definition 
PERSON_KEY    VARCHAR(16777216)  NO  
The person record''s key, the key of the hub that sent it; each ghost key once.
 
PERSON_ROLE    VARCHAR(16777216)  YES  
client, insured or agent; empty for the two ghost rows.
 
SOURCE_KEY    VARCHAR(16777216)  YES  
The source that first sent the record, a source_dim key; SYSTEM or ERROR for the ghost rows.
 
FIRST_KNOWN_DATE    DATE  YES  
The day the vault first received the record; empty for the ghost rows.
 
PERSON_NUMBER    VARCHAR(32)  YES  
The number the source gives the person: client number, insured number or national producer number.
 
FIRST_NAME    VARCHAR(16777216)  YES  
A client''s first name, from its current version; empty for insureds and agents.
 
LAST_NAME    VARCHAR(16777216)  YES  
A client''s last name, from its current version; empty for insureds and agents.
 
FULL_NAME    VARCHAR(129)  YES  
The person''s full name; an agent''s from the most recent sale naming the agent.
 
STATE    VARCHAR(16777216)  YES  
A client''s state, from its current version; empty for insureds and agents.
 
BIRTH_DATE    VARCHAR(16777216)  YES  
An insured''s birth date as sent; shown to consumers only through insured_dim''s mask.
 
ADDRESS    VARCHAR(16777216)  YES  
An insured''s address as sent; shown to consumers only through insured_dim''s mask.
