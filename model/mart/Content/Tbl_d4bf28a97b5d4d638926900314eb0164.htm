Definition  
One policy number per carrier; its plan as the most recent sale names it; a policy with no known carrier takes the unknown organization.
 
Note 
 
PreSQL   
DDL Code  CREATE TRANSIENT TABLE POLICY_DIM(
     POLICY_KEY                    VARCHAR(16777216)     NOT NULL,
     CARRIER_NAME                  VARCHAR(64),
     POLICY_NUMBER                 VARCHAR(32),
     PLAN_NAME                     VARCHAR(64),
     FIRST_NAMED_BY_SOURCE_KEY     VARCHAR(16777216),
     CONSTRAINT PK_POLICY_DIM PRIMARY KEY (POLICY_KEY)
)
;

POLICY_DIM Columns 
ColumnName  Domain  Datatype  NULL  Definition 
POLICY_KEY    VARCHAR(16777216)  NO  
The policy''s key in policy_h, carrier code and policy number together.
 
CARRIER_NAME    VARCHAR(64)  YES  
The name of the carrier that issued the policy, flattened from its organization; (unknown) when the carrier code names no organization record. A name, not a key, since dimensions meet only through facts (mart design D-17).
 
POLICY_NUMBER    VARCHAR(32)  YES  
The carrier''s policy number.
 
PLAN_NAME    VARCHAR(64)  YES  
The plan, as the most recent sale names it; empty when no sale names the policy.
 
FIRST_NAMED_BY_SOURCE_KEY    VARCHAR(16777216)  YES  
The first source to name the policy.
