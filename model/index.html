The architecture

From source to agent

Each layer has one job, and each is built and tested on every release. Today the mart reads the raw vault; next, it reads the business vault, where the integrated view is built once, and the agent authors the BI layer from the same metrics it answers with. For analytics served to hundreds of thousands of users, a ClickHouse serving layer reads the mart and runs the semantic layer's metrics as SQL, so every audience sees one version of each metric.
