Definition  
One row per policy, keyed by the issuing carrier''s code with the policy number; fed by Sunbelt Senior''s sales data and the carriers'' policy data.

POLICY_H Columns 
ColumnName  Domain  Datatype  NULL  Definition 
HK_POLICY_H    VARCHAR(16777216)  NO  
The hash key of policy_h: the hash of its business key, and its primary key.
 
CARRIER_CODE    VARCHAR(8)  YES  
The carrier''s code, such as NFL for Northfield Life or PMC for Pinecrest Mutual. A policy number is unique only within its carrier, so the code is part of the key.
 
POLICY_NUMBER    VARCHAR(32)  YES  
The policy number as the carrier issued it, first sighting kept; with the carrier code, the policy''s business key.
 
LDTS    CHAR(10)  YES  
The load time: when the vault received this row, in UTC.
 
RSRC    VARCHAR(16777216)  YES  
The record source: the code of the source system that sent the row, a key to the source system seed.
